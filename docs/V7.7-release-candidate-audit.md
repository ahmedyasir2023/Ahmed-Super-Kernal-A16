## Size blocker and mitigation
- The V7.7 CI-produced `Image.gz` was 19,649,991 bytes, *1,479 bytes larger* than the reserved V7.2 boot kernel page span 19,648,512 bytes. A direct substitution must FAIL.
- Decompress that pinned binary, recompress the **exact same uncompressed Linux Image** using deterministic Python `gzip.compress(..., compresslevel=9, mtime=0)`, SHA-256 pin the result and confirm identical decompressed bytes. Optimized gzip length 19,648,493, leaving **only 19 bytes**; kernel placement is safe only for these exact pinned bytes.
- Pinned original V7.7 CI Image.gz SHA-256: `53b287560741f83e64b672c3cde2ea6bdbd97310ea2e7febe7b73731ced747ba`.
- Pinned gzip9 Image.gz SHA-256: `33367173900cd24093c5dc4c3ba64c94ceddc2f790a3439cb612e81b98023ab2`.
- Absolute size and hash MUST NOT be reused for a future rebuild without rerunning all checks.

## Scope of repository
This GitHub branch contains **only release-engineering source, synthetic tests and audit documentation**. The proprietary user-owned Boot and the candidate/rollback ZIPs are NOT uploaded to GitHub. The local generator and its report were provided to the owner separately.

## Release blocker
CI and synthetic offline checks prove only structural integrity, not hardware compatibility. Do not flash before an explicit on-device test decision with independent off-device OrangeFox Boot backup. Assess KernelSU root, fingerprint, DT2W, suspend, thermal, Wi-Fi/mobile network, app launch/PSI, and screen-off battery drain. DeepDoze 600s and wake policy stay unchanged in source, but energy impact cannot be proved offline.

A proper *final release* requires on-device tests. Until then, this remains experimental and **NOT approved for flashing**.
