# AY A16 V7.3 Stage 1 — Evolution X memory compatibility

This is an experimental KernelSU Next module. It is not a new flashable kernel.

Input: user-provided Evolution X Android 16 Vendor files for RMX2170, dated November 2, 2026. The vendor init writes 140 to background memory cgroup swappiness, although the pinned kernel memcg handler rejects values above 100.

On the exact expected build only, after boot, save current background cgroup swappiness and set the single cgroup knob to 100. Pause via KernelSU Manager Action to restore old value immediately. Uninstall also rolls back.

No edits to Boot, CPU/GPU, HyperSpeed, DeepDoze, global VM, ZRAM, LMKD, kswapd count, SELinux, thermal, DT2W, fingerprint or KernelSU Next. Benefit is unproven and greater swapping may worsen stutter; if so pause/remove the module. Keep V7.2 boot and its OrangeFox recovery ZIP.

INSTALL ONLY THROUGH KERNELSU MANAGER. Not compatible with OrangeFox recovery.

Source: Desktop.zip, etc/init/hw/init.qcom.rc.
Kernel reference: https://github.com/realme-atoll/android_kernel_realme_sm7125/blob/10380039ddcd6ead841e1fc4ca744a2dd6e92fb8/mm/memcontrol.c
