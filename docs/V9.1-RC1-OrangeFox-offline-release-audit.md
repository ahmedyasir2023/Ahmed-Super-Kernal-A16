## Kernel delta and measured claims

- `mm/vmscan.c` guarded single additional reclaim pass (global one-second gate) is intended to mitigate bursty memory PSI; root-only opt-out remains.
- V9 CPUBoost, DT2W, DeepDoze 600s, one-kswapd default, thermal, KernelSU Next and SUSFS sources remain under existing CI invariants.
- **Physical boot status:** V9.1 RC1 subsequently booted on the RMX2170. KernelSU root UID 0 and SELinux Enforcing were confirmed in the first-boot report. The same report did **not** verify physical fingerprint operation, physical DT2W, DeepDoze entry, screen-off drain, or suspend residency.
- **Performance/power status:** no measured claim of V9.1 speed, memory PSI improvement, or battery improvement is established. The first-boot capture was short and not workload/uptime-matched against V9 RC1.1; see the [first-boot hardware audit](V9-1-RC1-firstboot-hardware-audit.md).

Do not merge this PR as stable on offline evidence alone.
