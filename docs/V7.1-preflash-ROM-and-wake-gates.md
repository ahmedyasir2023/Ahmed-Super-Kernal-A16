# V7.1 release preparation / rollback gate

The V7 firmware builder compiles Image.gz and exact-match DTBs, but cannot
emit a safe OrangeFox package based on an unrelated Android 14 kernel.

## New safeguards

- A stale 600-second timer from an earlier OFF interval can never cap a fresh
  OFF interval prematurely after rapid OFF -> ON -> OFF transitions.
- The V7.1 patch checks the last panel blank in jiffies and defers the worker
  for the remaining time rather than using a polling loop.
- The ROM audit checks original \`boot.img\`, \`dtbo.img\`, \`vbmeta.img\`,
  and \`vbmeta_system.img\` against the exact November 2, 2026 pinned
  Evolution X Android 16 manifest for Realme 7 Pro RMX2170.
- No AVB flag rewrite, no bootloader unlock operation, no non-stock dtbo,
  no flashing and no new boot image is performed by this audit.

## Run the audit when matching ROM files are available locally

    python3 scripts/v7/preflash_audit.py \
      --boot /path/to/EvolutionX-A16/boot.img \
      --dtbo /path/to/EvolutionX-A16/dtbo.img \
      --vbmeta /path/to/EvolutionX-A16/vbmeta.img \
      --vbmeta-system /path/to/EvolutionX-A16/vbmeta_system.img \
      --report audit/rom-preflight.txt

**An audit pass does not verify the currently installed device boot
partition** and does not grant permission to flash the unsigned custom kernel.
The device's installed ROM/bootloader state and signed external AVB chain need
independent checks.

The previously provided AY-Shadow V5 RC2 ZIP is for MelloDerp Android 14,
with a different Linux 4.14.357 kernel, and MUST NOT be used as an
Android 16 OrangeFox kernel payload.

The current GitHub artifact remains NONFLASHABLE and untested on hardware.
