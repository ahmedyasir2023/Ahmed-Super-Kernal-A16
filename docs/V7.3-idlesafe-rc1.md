# Ahmed Super Kernal A16 V7.3 — IdleSafe RC1 (development only)

Branch: v7-3-idlesafe-rc1, forked directly from the verified bootable V7.2 commit 6c538bcba3769d7d54755d34764d29d86ae7ccd9.

## Screen-off power baseline

Owner-submitted RMX2170 Evolution X Android 16 screenshots: 17:21 and 17:51 both show 86% battery. This supports **no change in displayed integer percentage over 30 minutes**, not zero actual energy use or proof of full suspend. It is a valuable qualitative baseline.

## Changes

1. **No modifications to V7.2's cpu-boost.c, touchscreen driver, or ZRAM implementation.** CI records their SHA-256 after the V7.2 pipeline and checks all three files are **byte-for-byte unchanged** by V7.3.
2. Adds a two-line NULL task guard to the vendor multi-kswapd CPU-online callback in mm/multi_kswapd/multi_kswapd.c. It prevents set_cpus_allowed_ptr(NULL, mask) if a worker entry is absent. Does **not** change reclaim rates, thread count, OOM thresholds, ZRAM, LMKD or loop pacing.
3. Adds fail-closed idle, 600-second deferrable DeepDoze, wake/race, no extra polling, touch, root, thermal, and security compile guards.
4. Retains touch 72%/105 ms, wake 82%/155 ms and scheduler boost 3.

## No unsupported claims

- No measurable improvement of 60%+ memory PSI or 100% kswapd claimed: further causality evidence is needed.
- Battery percentage is rounded, and a sleeping phone may never run the deferrable 600-second timer before wake.
- **CI artifact: non-flashable kernel diagnostics only.** No OrangeFox ZIP produced. Do not install.
- Hardware battery, idle residency, application latency, root, DT2W and fingerprint remain to be verified before any release.

## Isolation

The earlier V7.3 experimental KernelSU memory swappiness module on v7-3-rom-memory-compat is **not integrated** in this kernel branch, and the V7.2 OrangeFox rollback remains available.
