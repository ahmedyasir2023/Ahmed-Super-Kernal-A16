# V7.5 acceptance criteria — hardware testing deferred

The user requested source development only; keep V7.2 installed until a flashable RC and informed device testing are explicitly requested.

## Release blockers
1. GitHub Actions ARM64 compile, root objects and original ROM DTB match must pass.
2. Regressions: V7.2 DT2W active at boot, fingerprint, touch 72%/105ms, wake 82%/155ms, scheduler3; unchanged 600-second deferrable DeepDoze.
3. The V7.5 source patch must remove only the premature waiter-zero exit from balance_pgdat. Keep failures, watermarks, freezer and stop intact.
4. Physical test must compare V7.2 vs V7.5 under comparable memory pressure, app workload and screen-off intervals. Use delta of pgscan_kswapd/pgsteal_kswapd, swap-in/out, PSI avg10/avg60 and worker CPU, rather than idle battery percentage alone.
5. Battery acceptance: no repeatable deterioration of screen-off drain or wake/suspend behavior. Battery integer 86% over 30 minutes is a reference observation, not a sub-mAh energy measurement.
6. Stop/revert if severe PSI, freezes, thermal distress, root/DT2W/fingerprint failure, or suspend failures increase.
7. Do not promote the draft PR or label kswapd 100% fixed solely from passing CI.

## Known limitations
The Android ROM's `kswapd_threads=2` value and `direct_swappiness` are runtime settings, not changed in V7.5. Even with watermark-driven reclaim fixed, memory cgroup policy, non-reclaimable zone pressure or application allocation rates may continue to cause stutter.
