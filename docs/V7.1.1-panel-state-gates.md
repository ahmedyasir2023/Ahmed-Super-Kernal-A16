# V7.1.1: panel tracking / release readiness

Latest CI includes a small correctness fix to the V6 notifier used by V7.

Previously the writable \`ay_screenoff_saver\` flag allowed a return before
updating \`ay_screen_on\`. If toggled between blank and unblank, the internal
state could remain out of sync. Now the driver tracks both notifications
even when the optional saver is disabled. DeepDoze only arms when the
saver is enabled. The one-shot 600s clock cap remains deferrable; the
wake transition removes it without waiting for 600 seconds.

**This is NOT proof of the runtime behavior on RMX2170.** The build retains
the "NONFLASHABLE" policy until exact original Android 16 boot files and
the installed verified boot state can be independently checked. The
repository contains a SHA256 pinned preflight tool at
\`scripts/v7/preflash_audit.py\`, but no matching original ROM boot image.

The uploaded AY-Shadow V5 RC2 OrangeFox package does not establish
Android 16 compatibility and must not be repurposed as an A16 installer.
