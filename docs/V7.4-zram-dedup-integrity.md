# V7.4 ZRAM integrity - experimental, NONFLASHABLE

Base: proven V7.3 IdleSafe CI; V7.2 remains installed on the phone. No request to test the newer versions.

Verified kernel source issue (conditional on dedup enabled): zram_entry_free() preserves shared compressed data until its last reference. But original zram_free_page() subtracts compr_data_size for every freed slot, causing an unsigned accounting underflow for shared data.

Fix: return bool from zram_entry_free() indicating whether the physical backing object was released. Decrement compressed data size ONLY if true. The seven-field mm_stat is retained. New dedup_stat sysfs reports existing duplicate compressed bytes and metadata bytes, read-only; no new timers, counters or workers.

Important: CONFIG_ZRAM_DEDUP enabled in build does NOT prove zram0/use_dedup enabled at runtime. zram->use_dedup defaults false. This repair does not prove cause of severe PSI or kswapd CPU. Also discover per-kernel direct_swappiness separately from global swappiness. Probe script is read-only.

DeepDoze 600 seconds, InstantWake, 72%/105ms input boost, 82%/155ms wake boost, scheduler boost 3, touch, root, SELinux and thermal are unchanged. No kernel reclaim tuning in this stage. Build output nonflashable.
